# /bibuzaohua

手动触发笔补造化 skill。把一段汉语从「正确但无魂」拔到「有骨、有气、有兴象」。

先读 `SKILL.md` 与 `reference/shijing-chuci.md`,再按下方执行。

## 入参解析

`$ARGUMENTS` 第一词若为「作韵文 / 重写 / 诊断 / 命名」之一,即任务类型;否则按文本内容自动判定:
- 给的是诉求/题目 → 作韵文
- 给的是一段已有文字 → 先诊断后重写
- 提到品牌/产品/仪式/取名 → 命名

## 执行(笔补造化重写四步)

1. **立象(兴)**——动笔前先找一个能承载主旨的外物之象,以象起情,不直陈(避免只用赋)。
2. **铸骨(风骨之骨)**——确立硬的立意与结构,删去支撑不住主旨的辞藻。
3. **贯气(风骨之气)**——让一股情感/精神的生命力贯穿全篇,首尾呼应。
4. **去饰存真(楚辞)**——逐句自检:为情服务还是为辞造情?凡饰胜于情者删或改。

诊断类额外先答两问:**有骨吗?**(立意硬否、结构立得住否)**有气吗?**(是否一气贯穿,还是字字正确而通篇无生气)。

## 铁律

- 凡引《诗经》《楚辞》原句必注「书·篇」;不确定原文只描述框架,**绝不杜撰原文或篇目**。
- 情感节制(哀而不伤,乐而不淫);辞为情役,不为辞造情。
- 不立华夏本位。

## 输出格式

先打状态行,再给正文,最后(诊断/重写类)附「改了什么·为什么」三五条。

```
[笔补造化 | 任务:{作韵文/重写/诊断/命名} | 主象:{X} | 骨:{立意一句} | 气:{贯穿主线一句} | 典源核验:{已注书·篇 / 不涉}]
```
